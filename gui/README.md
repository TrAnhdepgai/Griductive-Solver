# Griductive GUI

Run the browser UI against the team's Python engine from the repository root:

```bash
python -m src.engine.gui_server
```

Open <http://127.0.0.1:8001>. The daily cards, verdict calls, hints, single
agent steps, auto solve, and restart use the repository puzzles and
`LocalGameEngine` / `LogicAgent`. The browser does not receive hidden solution
statuses or unrevealed clues. Embedded demo puzzle data has been removed, and
the game controls now use the backend API instead of the former mock solver.

## Daily puzzles

Every calendar date has its own puzzle, generated by `src/engine/daily.py` the
first time the date is opened and cached in `puzzles/daily/<YYYY-MM-DD>.json`
(git-ignored). Difficulty follows the weekday ladder of `tools/generate_weekly.py`
(easy Monday ... evil Sunday). The seed comes from the date, so each day is a new
puzzle and the same date always gives the same puzzle. The playable window is a
fixed 183 days (about 6 months) ending today: each new day adds today's puzzle and
deletes only the oldest one, every other date keeps its puzzle.

On start the server builds today's puzzle first, then fills the rest of the window
in the background (parallel, newest first). 5x5 days (Fri-Sun) take 5-30 s each;
a full window takes about 3 minutes on 16 cores. To build it ahead of a demo:

```bash
python -m src.engine.daily            # all cores; --jobs N to limit
```
